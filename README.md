# Beecrowd 1048 - Aumento de Salário



## Descrição



Este programa resolve o problema 1048 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém um valor de ponto flutuante que representa o salário do funcionário.



## Saída



O programa apresenta o novo salário, o valor do reajuste ganho e o percentual de reajuste.
